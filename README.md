## Quick Start

```bash
git clone https://github.com/Ayushkumarsingh09/astralumen.git
cd astralumen
npm install
npm run dev
npm run build
```

For WordPress/PHP packages, skip `npm` and follow the deployment docs in `docs/` / `DEPLOY*.md`.
